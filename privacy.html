Privacy Policy

When you use the bot, it records information about the request so the bot can process and track it.

Information recorded

  • URL: The URL you submitted.
  • User ID: Your Discord user ID.
  • Channel ID: The Discord channel ID where the command was ran.
  • Message ID: The Discord message ID where the command was ran.
  • Status: The request's status. Such as pending, archived, downloading, etc.
  • Timestamp: When the request was recorded.
  • Trace ID: A randomly generated ID for the request.
  • Log: Commands and the output of the commands when getting ran such as yt-dlp and ia.
  • Storage: The amount of storage a specific request took up in bytes.

Questions
